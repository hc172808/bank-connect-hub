## Architecture
- `src/locales/en.ts` — master type source (`Translations = typeof en`)
- `src/locales/{es,fr,pt,ar}.ts` — each typed as `Translations`, full translation objects
- `src/locales/index.ts` — exports `translations`, `LOCALES`, `Locale`, `LOCALE_NAMES`, `LOCALE_FLAGS`, `RTL_LOCALES`
- `src/contexts/LanguageContext.tsx` — `LanguageProvider` sets `document.dir` and `document.lang`; persists to `localStorage("vbank_language")`
- `src/hooks/useT.ts` — convenience re-export: `useT()` → `{ t, locale, isRTL }`
- `src/components/LanguageSelector.tsx` — full-width button list, checkmark on active

## Wiring
- `main.tsx` wraps `<LanguageProvider>` outside `<ThemeProvider>` outside `<App>`
- Language picker is embedded in `Profile.tsx` in the Appearance card (below Color theme)

## RTL
- Only Arabic (`ar`) sets `dir="rtl"` on `<html>`
- `RTL_LOCALES = ["ar"]` in `locales/index.ts`

**Why:** Keeping LanguageProvider at root (outside ThemeProvider) ensures all theme-aware components can also consume `useT()` without circular context deps.
